                  Modes d'apprentissage

                  Paramétrage des modes d'apprentissage

                  Un mode d'apprentissage définit à quelle vitesse l'intervalle entre deux révisions d'une fiche augmente selon ta réponse (Encore, Difficile, Bien, Facile). Chaque boîte (ou dossier entier de boîtes) se voit affecter un mode depuis la page Gérer. Modifier un mode ici change donc le rythme de révision de TOUTES les boîtes qui l'utilisent actuellement.
